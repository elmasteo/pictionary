# Pictionary Familiar

App web estática hecha únicamente con HTML, CSS y JavaScript.

## Incluye
- 9 temas.
- 60 palabras por tema (20 por dificultad).
- Dificultad Fácil / Medio / Difícil.
- Temporizador 30 / 45 / 60 / 90 segundos.
- Rondas ilimitadas sin repetir palabra hasta agotar el conjunto.
- Botón de pausa, nueva palabra y acierto.
- Sonidos simples sin archivos externos.
- Diseño responsive para celular, tablet y computador.
- Funciona sin backend y puede publicarse directamente en Netlify, Vercel o GitHub Pages.

## Publicación en Netlify
Arrastra la carpeta del proyecto a Netlify Drop o conecta el repositorio Git.

No requiere build ni dependencias.
